# CardioCare

Next.js and TypeScript viewer for a real human heart. Drag to orbit, scroll to zoom, and change the heart rate to watch a simplified beat.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The heart geometry is the female Visible Human reference from the HuBMAP CCF 3D Reference Object Library, used under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). See `public/models/NOTICE.txt`.
